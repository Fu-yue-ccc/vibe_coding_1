## 开始使用 Warp 与 Oz

上手 Warp（智能体开发环境，Agentic Development Environment）与 Oz（面向云端智能体的编排平台）。

Warp 是一个智能体开发环境，它把现代终端与强大的智能体结合在一起，帮助你构建、测试、部署和调试代码。Warp 的 AI 由 Oz 驱动 —— Oz 是面向云端智能体的编排平台。

Warp 把现代终端与 Oz（面向云端智能体的编排平台）合为一体

Warp

Warp 就是你工作的地方 —— 一个为「与智能体一起写代码」而生的、快速而现代的终端。

关键能力：

- **智能体模式（Agent Modality）**：在干净的命令终端与专门的多轮智能体会话视图之间切换。
- **现代终端体验**：光标移动、基于块（block）的导航、多行编辑、语法高亮与丰富的补全。用 Rust 构建，性能卓越。
- **代码编辑器**：文件树、支持 LSP 的代码编辑器，以及交互式代码评审体验。
- **编程智能体集成**：支持语音输入、用 @ 选择处理终端里的图片，兼容 Oz 或 Claude Code、Codex 等智能体。

深入了解 Warp 的核心功能

### Oz：面向云端智能体的编排平台

Oz 是面向云端智能体的编排平台，为 Warp 的全部智能功能提供动力。Oz 的设计目标是规模化地协调智能体 —— 理解你的代码库、自主执行任务，并适配你的工作流。Oz 天生支持多模型（multi-model by design），让你能为每个任务挑选最合适的 LLM。

Oz 有两种运行模式：

**本地智能体（Local agents）**

直接在 Warp 应用内运行，提供实时、可交互的编程协助。

- 在你的代码库中编写与重构代码
- 调试问题并修复错误
- 运行命令并解读结果
- 规划并执行多步骤任务

本地智能体让你始终掌握控制权。你可以审查改动、在任务中途调整智能体的方向（steer），并在动作真正执行前予以批准。

→ 开始使用本地智能体

**云端智能体（Cloud agents）**

Oz 云端智能体在 Warp 的基础设施（或你自己的基础设施）上后台运行，实现规模化自动化。

- **触发器（Triggers）**：响应来自 Slack、Linear、GitHub 或自定义 webhook 的事件
- **定时任务（Schedules）**：运行依赖更新、死代码清理等周期性任务
- **并行（Parallelism）**：跨仓库或跨任务并发运行多个智能体
- **可观测性（Observability）**：每一次运行都被追踪、可审计，并可与团队共享

云端智能体非常适合那些不需要你立刻关注的工作，例如 PR 评审、issue 分诊、日常维护，以及由集成驱动的工作流。

→ 了解云端智能体

### 两者如何协同工作

Warp 与 Oz 在本地与云端开发之间提供统一体验：

- **同一个智能体，随处可用**：无论你是在 Warp 中交互式工作，还是在云端运行智能体，用的都是同一套底层智能体能力。
- **无缝交接（Seamless handoff）**：在云端启动任务，需要亲手掌控时再在本地 Warp 中接手，进度与上下文都不会丢失。
- **共享上下文**：Warp Drive、Rules 与 MCP 服务器同时作用于本地与云端智能体，因此团队的知识与工具随处可用。
- **团队协作**：共享智能体会话、审查智能体的动作、调整正在运行任务的方向 —— 无论任务是由谁发起的。

### 多模型支持

Oz 天生支持多模型。你可以从一份精选的顶级模型清单中挑选自己偏好的 LLM。

### 隐私与安全

Warp 符合 SOC 2，并与所有签约的 LLM 供应商执行零数据留存（Zero Data Retention）政策。客户的 AI 数据不会被留存、存储或用于训练。

Warp 的 AI 功能可在「设置 > AI」中全局关闭。
